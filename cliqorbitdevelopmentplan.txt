## 7. REQUIRED TECHNOLOGY STACK

Build the website using Angular as the primary framework.

### Frontend
- Angular with a current stable version; target Angular 20 compatibility.
- TypeScript with strict typing.
- Standalone Angular components.
- Angular Router where appropriate.
- Angular Reactive Forms.
- RxJS.
- Angular Signals where useful for local reactive state.
- HTML5 and semantic markup.
- SCSS or well-organized CSS.
- Bootstrap Icons for interface icons.

### Animation and graphics
- CSS animations and transitions.
- SVG for orbital diagrams, signal flows, and lightweight visualizations.
- A compatible motion library such as GSAP only when it adds meaningful value.
- Canvas or WebGL only if justified by the experience and performance budget.

Avoid adding large dependencies for simple animations.

### Backend integration readiness
The first release is frontend-focused and must run with mock data.

Prepare clean interfaces and service boundaries for a future Python FastAPI backend.

Potential future endpoints include:
- POST /api/contact
- GET /api/demo/campaigns
- GET /api/demo/analytics
- POST /api/ai/insights

These are proposed endpoint contracts, not existing live APIs.

Do not make the website dependent on a real backend during the initial development phase.
